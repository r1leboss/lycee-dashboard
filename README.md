
# Lycée Dashboard

A free, open-source web app for high school students to stay organized:
grade calculator, homework planner, flashcards, Pomodoro timer and
revision scheduler, all in one place.

## Status

Work in progress. The first module (grade calculator) is under development.

## Planned features

- [ ] Grade calculator with coefficients and goal simulator
- [ ] Homework planner with deadlines and reminders
- [ ] Pomodoro timer with study statistics
- [ ] Flashcards with spaced repetition
- [ ] Smart revision planner
- [ ] Data export / import (JSON backup)
- [ ] Installable on phone (PWA)

## Privacy

Your data stays in your browser. Nothing is sent to a server, and no
account is required. Each user has their own private data.

## Getting started

1. Clone the repository:
```bash
   git clone https://github.com/yourusername/lycee-dashboard.git
```
2. Open `index.html` in your browser (or use the VS Code extension
   Live Server).

## Tech stack

HTML, CSS and vanilla JavaScript. No framework, no build step.
